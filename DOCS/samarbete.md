# Gemensamt repository i ett utvecklingsteam
Det är en central lagringsplats på nätet (Github) där ett utvecklingsteam samlar all sin kod, dokumentation och filer för ett program projekt. 
## Vad ett gemensamt repository används till i ett utvecklingsteam
- Alla jobbar mot samma version. Alltså innehållet ändras efter att man pushat och pullat och man behöver inte skicka till exempel mejl med kod fram och tillbaka för att hålla sig uppdaterad på allt.
- Man kan se vem som har gjort vad. Ifall något går fel kan man fråga rätt person eftersom man kan se vem som har gjort just den delen.
- Man kan gå tillbaka i historiken. Ifall man är i ett steg där hela koden inte fungerar så kan man gå tillbaka till en version som fungerade sist och börja därifrån. Eller testa sig fram från den versionen och se vad som gick fel.
