# Praktisk Verktygsuppgift 
## Vad övningen går ut på 
Denna övningen går ut på att man ska lära sig använda VS Code, Git och versionshantering, och om Github. Jag lär mig hur jag ska använda kommandon för att kunna vänja mig med att använda terminal. Kursen är introduktion till modern utvecklar roll, i programmet mjukvaruutveckling.
## Git-kommandon jag använt
- git init - Använde för att skapa git repository
- git status - använde för att se det aktuella läget i mappen.
- git add - använde för att förbereda mina ändringar innan jag gör git commit
- git commit -m "meddelande" - använde för att spara mina förberedda ändringar som en version i historiken. Texten efter -m är ett meddelande som beskriver vad jag ändrade.
- git log - använde jag för att visa historiken över alla commits som har gjorts i projektet. 
- git branch -M -  använde för att döpa om min gren (branch) från master till main, så att den heter samma sak som grenen på GitHub.
- git remote add - Använde för att koppla ihop repon som jag skapade här och repon som jag skapade i github.
- git push - laddade upp mina sparade ändringar till github
